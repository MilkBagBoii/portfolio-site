# Game Developer Portfolio

Static portfolio site for a game developer with multi-engine experience, itch.io links, featured projects, and a final playable/released games section.

## Edit Your Info

Open `script.js` and update the `portfolio` object at the top:

- `name`, `initials`, `itchUrl`, and `email`
- `summary` and `status`
- `engines` for the engines you want to highlight
- `projects` for your games, tools, prototypes, and released work

Any project with a `publicUrl` automatically appears in the final "Playable and released" section.

## Open The Site

Open `index.html` in your browser. No build step or dev server is required.
